## Getting Started

Welcome to the VS Code Java world. Here is a guideline to help you get started to write Java code in Visual Studio Code.

## Folder Structure

The workspace contains two folders by default, where:

- `src`: the folder to maintain sources
- `lib`: the folder to maintain dependencies

Meanwhile, the compiled output files will be generated in the `bin` folder by default.

> If you want to customize the folder structure, open `.vscode/settings.json` and update the related settings there.

## Dependency Management

The `JAVA PROJECTS` view allows you to manage your dependencies. More details can be found [here](https://github.com/microsoft/vscode-java-dependency#manage-dependencies).

## CIFRAS Y LETRAS

## 1. Descripción del proyecto

Este proyecto consiste en desarrollar en Java un juego inspirado en el concurso Cifras y Letras, en el que dos jugadores compiten mediante diferentes pruebas relacionadas con las palabras, los números, la lógica y la rapidez mental.

El programa dispone de un menú principal desde el que se puede acceder a los distintos modos de juego, configurar los ajustes y salir del programa.

El objetivo es poner en práctica los conocimientos adquiridos en programación Java, utilizando funciones, bucles, condicionales, variables, cadenas de caracteres y generación de números aleatorios.

## 2. Pruebas del juego

El programa incluye las siguientes pruebas:

-- Prueba 1: La cifra exacta

Prueba desarrollada por uno de los integrantes del equipo, siguiendo las indicaciones del enunciado del proyecto.

-- Prueba 2: La palabra más larga

El programa genera 10 letras aleatorias, incluyendo al menos 4 vocales y 4 consonantes.

Cada jugador debe formar la palabra más larga posible utilizando únicamente las letras disponibles.

Se comprueba la validez de las palabras introducidas y se determina el ganador según su longitud.

-- Prueba 3: La calculadora humana

Los jugadores deben resolver una serie de operaciones matemáticas generadas aleatoriamente.

Las operaciones pueden ser sumas, restas, multiplicaciones y divisiones.

El programa registra el tiempo empleado por cada jugador y aplica una penalización de 20 segundos por cada respuesta incorrecta.

Gana el jugador que complete las operaciones en el menor tiempo posible, incluyendo las penalizaciones.

-- Prueba 4: Cuantas más palabras mejor

Prueba original creada por el equipo para ampliar las funcionalidades del juego.

## 3. Menú principal

El programa cuenta con un menú que permite seleccionar las siguientes opciones:

Modo concurso.

Modo rápido.

Ajustes.

Salir.

También se ha incorporado una presentación visual del título "CIFRAS Y LETRAS" utilizando colores y caracteres ASCII.

## 4. Tecnologías utilizadas

Lenguaje de programación: Java.

Entorno de desarrollo: Visual Studio Code.

Control de versiones y entrega: GitHub.

Inteligencia artificial: utilizada como apoyo para la creación del diseño inicial del título del juego.

## 5. Instrucciones de ejecución

Descargar el proyecto desde este repositorio de GitHub.

Tener instalado Java en el ordenador.

Abrir el proyecto en un entorno de desarrollo compatible con Java.

Localizar la clase principal que contiene el método main.

Ejecutar el programa.

Seleccionar una opción del menú principal para comenzar a jugar.
